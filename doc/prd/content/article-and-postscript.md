# Content Article / Postscript 业务设计

## 1. 业务定位

文章主题是社区内容的核心对象。P0 只完整实现 `normal` 普通主题；问答、抽奖、投票、专栏等类型只预留扩展机制，不对外开放。

## 2. 文章类型

| 类型 | P0 状态 | 后续规划 |
| --- | --- | --- |
| `normal` | 完整实现 | 普通社区主题 |
| `qa` | 预留 | P1 实现问答、悬赏、采纳 |
| `lottery` | 预留 | P1 实现抽奖配置、参与、开奖 |
| `poll` | 预留 | P1 实现投票配置、选项、记录 |
| `column` | 预留 | P1 实现专栏、目录、订阅 |

## 3. P0 文章功能

| 功能 | 使用方 | 说明 |
| --- | --- | --- |
| 创建草稿 | BBS | 用户创建普通文章草稿 |
| 编辑草稿 | BBS | 作者编辑标题、正文、评论开关、打赏区内容等 |
| 发布文章 | BBS | 只允许发布草稿 |
| 查询文章详情 | BBS、管理端 | content 返回文章完整事实字段 |
| 查询文章列表 | BBS、管理端 | 返回当前页所有文章完整详情 |
| 归档文章 | BBS、管理端 | 作者或管理端归档，归档后只读 |
| 取消归档 | 管理端 | 仅管理端接口，BBS 不对外提供 |
| 公开/私有 | BBS | 作者控制可见性 |
| 丢弃草稿 | BBS | 作者丢弃 draft |
| 浏览文章 | BBS | 增加浏览量，登录态写浏览历史 |
| 内容治理 | 管理端 | 隐藏、锁定、恢复等治理状态变化 |

## 4. 文章状态模型

| 维度 | 字段 | 状态 | 说明 |
| --- | --- | --- | --- |
| 生命周期 | `publish_status` | `draft` / `published` / `archived` | 作者侧生命周期 |
| 可见性 | `visibility` | `public` / `private` | 作者设置的可见范围 |
| 治理限制 | `restriction` | `none` / `hidden` / `locked` | 管理侧治理状态 |

## 5. 状态可见性

| 状态组合 | 普通用户 | 作者 | 管理员 | 评论/互动 |
| --- | --- | --- | --- | --- |
| `draft` | 不可见 | 可见 | 可见 | 不允许 |
| `published + public + none` | 可见 | 可见 | 可见 | 允许 |
| `published + private + none` | 不可见 | 可见 | 可见 | 普通用户不允许 |
| `archived + public + none` | 可见 | 可见 | 可见 | 不允许 |
| `hidden` | 不可见 | 可提示被隐藏 | 可见 | 不允许 |
| `locked` | 可见 | 可见 | 可见 | 不允许 |

## 6. 编辑与发布规则

| 场景 | 规则 |
| --- | --- |
| 创建草稿 | 只允许创建 `normal` 类型 |
| 编辑草稿标题 | 允许 |
| 编辑草稿正文 | 允许 |
| 编辑草稿评论开关 | 允许 |
| 编辑草稿打赏区内容 | 允许 |
| 编辑草稿 tag | 不通过草稿接口处理，使用独立绑定/解绑接口 |
| 发布文章 | 只允许从 `draft` 发布 |
| 发布后修改正文 | 不允许 |
| 发布后修改评论开关 | 不允许 |
| 发布后修改打赏区内容 | 不允许 |
| 发布后作者修改 tag | 不允许 |
| 发布后添加附言 | 允许 |
| 归档后编辑 | 不允许 |
| `hidden/locked` 后编辑 | 不允许 |

## 7. 归档规则

| 操作 | 使用方 | 规则 |
| --- | --- | --- |
| 归档 | 作者、管理端 | 已发布文章可归档 |
| 取消归档 | 管理端 | 仅管理端开放，BBS 不对外提供 |
| 归档后浏览 | 可浏览，前提是 public 且非 hidden |
| 归档后评论 | 不允许 |
| 归档后互动 | 不允许 |
| 归档后附言 | 不允许 |
| 归档后编辑 | 不允许 |

## 8. 查询规则

### 8.1 单篇查询

返回文章完整事实字段，不聚合作者、tag、评论预览、Markdown 渲染等展示信息。

### 8.2 列表查询

返回当前页所有文章完整详情。BBS 根据页面需要自行截断摘要、提取封面、渲染 Markdown、聚合作者和评论信息。

### 8.3 查询参数

| 参数 | 说明 |
| --- | --- |
| `article_ids` | 按文章 ID 列表查询 |
| `author_id` | 按作者查询 |
| `domain_id` | 按大分类查询 |
| `tag_id` | 按节点查询 |
| `type` | 按文章类型查询 |
| `publish_status` / `publish_statuses` | 按生命周期状态查询 |
| `visibility` / `visibilities` | 按可见性查询 |
| `restriction` / `restrictions` | 按治理限制查询 |
| `keyword` | 标题/正文关键词，P0 用 DB 基础能力，P2 迁移搜索服务 |
| `created_at_start/end` | 创建时间范围 |
| `published_at_start/end` | 发布时间范围 |
| `updated_at_start/end` | 更新时间范围 |
| `order` | 最新、最热、最多回复、最多浏览等 |

## 9. Article Schema 原则

`content_articles` 只放所有文章类型共有字段。

| 字段类型 | 字段 |
| --- | --- |
| 基础内容 | `id`、`title`、`content`、`cover_image_url` |
| 打赏区 | `reward_content`、`reward_points` |
| 状态 | `publish_status`、`visibility`、`restriction`、`type` |
| 配置 | `commentable` |
| 时间 | `published_at`、`archived_at`、`edited_at` |
| 统计 | `view_count`、`like_count`、`thank_count`、`collect_count`、`reward_count`、`reply_count` |
| 操作人 | `created_by`、`updated_by` |
| 审计 | `created_at`、`updated_at`、`deleted_at` |

> `reward_content/reward_points` 在 P0 作为普通文章通用打赏区能力保留；问答悬赏、抽奖配置、投票配置、专栏信息不进入文章主表。

## 10. 类型扩展表原则

| 类型 | 扩展表 | 说明 |
| --- | --- | --- |
| QA | `content_article_qa` | 悬赏、采纳、结算状态 |
| 抽奖 | `content_article_lottery` | 奖品、开奖时间、参与规则 |
| 投票 | `content_article_polls` | 投票规则、截止时间、展示规则 |
| 专栏 | `content_columns` / `content_column_articles` | 专栏信息和文章目录 |

## 11. 附言功能

| 功能 | 说明 |
| --- | --- |
| 添加附言 | 作者对已发布文章追加正文补充 |
| 查询附言 | 文章详情展示附言列表 |
| 附言治理 | 管理端可隐藏/锁定，P0 可预留 |

## 12. 附言规则

| 规则 | 说明 |
| --- | --- |
| 添加人 | 仅文章作者 |
| 文章状态 | 仅 `published + none` 文章可添加 |
| 草稿 | 不允许添加 |
| 归档 | 不允许添加 |
| hidden/locked | 不允许添加 |
| 编辑 | 附言发布后不允许编辑 |
| 展示 | 按创建时间正序展示 |

## 13. 设计理由

- 发布后不允许修改正文，保护讨论上下文和审计可信度。
- 附言作为发布后补充说明，替代正文继续编辑。
- 打赏区内容与感谢不冲突：感谢是固定积分奖励，打赏是解锁额外内容。
- 文章类型扩展使用独立表，避免文章主表被问答、抽奖、投票、专栏字段污染。
- 查询接口返回事实数据，展示聚合留给 BBS，保持 content 底层服务边界清晰。
- 取消归档仅管理端开放，避免作者反复恢复归档主题扰乱讨论秩序。
